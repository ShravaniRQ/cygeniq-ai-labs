# Cygeniq AI Labs: Security Guidelines

## 1. Access Control
- All employees must use Multi-Factor Authentication (MFA) for accessing company email and internal systems (including the GRC dashboard).
- Passwords must be at least 14 characters long and rotated every 90 days.

## 2. Data Classification
- **Public:** Can be freely distributed.
- **Internal:** For employee eyes only (e.g., org charts, general policies).
- **Confidential:** Requires specific authorization (e.g., HR records, unreleased financial data).
- **Restricted:** Highly sensitive data (e.g., customer PII, cryptographic keys). Access is strictly logged and audited.

## 3. Incident Reporting
If you suspect a data breach or a phishing attempt, you must immediately report it to the IT Security Team at `security@cygeniq.local` within 1 hour of discovery.
